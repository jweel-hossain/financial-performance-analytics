# Financial Overview & Strategic Performance Dashboard

## Project Overview
This project focuses on building a robust financial reporting solution that transforms raw transaction data into a strategic decision-making tool. The dashboard provides a high-level summary of financial health while allowing users to deep-dive into specific metrics like profitability and expense management.

## Key Features & Business Insights
**Core KPI Tracking**: Visualized real-time trends for **Revenue, Gross Profit, and COGS** to monitor overall business performance.
**Advanced Growth Analytics**: Developed custom DAX measures to calculate **Year-over-Year (YoY)** and **Month-over-Month (MoM)** growth, enabling quick identification of seasonal trends.
**Strategic Drill-Throughs**: Implemented drill-through capabilities to allow stakeholders to navigate from summary views to granular transaction details.
**Interactive Filtering**: Users can slice financial data by time periods, regions, or categories for targeted analysis

## Technical Implementation (Tools & Skills)
**Power BI Desktop**: End-to-end report development and publishing.
**DAX (Data Analysis Expressions)**: Created complex measures for time-intelligence, filter context manipulation, and dynamic KPIs...
**Power Query (ETL)**: Conducted extensive data cleaning, transformation, and shaping to ensure data integrity.
**Data Modeling**: Optimized the data structure using a 
**Star Schema** for efficient query performance and scalability.
